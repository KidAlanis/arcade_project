# 照片转像素换装角色：参考提示词

以下为用户提供的 IMG_6644.JPG 中提示词的文字识别稿。此文档用于照片角色测试；网站素材仅使用生成角色及其分层图，不包含原始个人照片。

【参考原则】上传照片决定人物性别、发型、服装、配饰、颜色及造型细节；Style Savvy 参考图决定人物比例、卡通程度、像素密度、背景质感及游戏 UI 风格。必须保留原人物的辨识度与穿搭特征。

【人物风格】人物明显卡通化，采用早期换装游戏比例：头部略大、身体纤细、四肢简化、大眼睛或游戏式眼型、五官简洁、平涂色块。必须具有明显的大颗粒像素、锯齿边缘和低分辨率游戏截图质感。禁止写实、现代 anime、高清插画、3D、精致游戏 CG。宁可粗糙、模糊、陈旧，也不要高清精致。

【造型还原】严格保留原图人物的发型、发色、服装款式、颜色、鞋履、包袋、眼镜、首饰及其他配饰。保留服装轮廓、主要色块、层叠关系和个人穿搭特色。面料细节可简化为像素色块，但不得随意改变造型或添加原图不存在的单品。

【画面形式】整体呈现 2000 年代早期掌机 / 网页换装小游戏中的角色剧情页或造型展示页。可根据照片自然选择不同构图：精品店、更衣室、街道、卧室、咖啡店、服装陈列室；全身角色 + 游戏菜单、半身角色 + 对白框、大头像 + 小型造型展示、角色对话场景等。不要变成现代时尚海报、杂志大片或品牌广告。

【背景与 UI】背景必须低清、柔和、像素化，具有古早游戏空间质感。可加入白色圆角对白框、像素字体、下一步箭头、简单菜单、角色状态窗口及换装按钮。UI 应符合 2000 年代早期少女换装游戏的视觉语言，避免现代 App 界面设计。

【对白内容】可根据人物穿搭与场景加入简短、自然的换装游戏台词，例如 “NEW LOOK!” “STYLE CHECK” “READY?” “OUTFIT COMPLETE!” “NEXT ▶”。文字应简短、有趣，符合古早换装小游戏氛围，避免大段文字或无关内容。

【系列统一性】不同照片生成的画面应保持统一的人物比例、卡通程度、大颗粒像素密度、低清画质、像素字体及 2000 年代换装游戏氛围。但允许根据人物穿搭变化姿势、镜头远近、背景、对白框位置和页面布局。不要机械复制同一模板，要像同一款游戏里的不同角色和剧情页面。

【最高优先级】① 保留原人物性别、辨识度与真实穿搭；② 明显卡通化、大颗粒像素、低清截图质感；③ 真实古早换装游戏截图感，拒绝高清精致化；④ 根据每张照片自然变化场景与构图；⑤ 最终画面必须像一张真正来自 2000 年代早期换装小游戏的截图。比例 16:9。
