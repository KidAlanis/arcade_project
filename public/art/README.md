Create a polished original pixel art landscape background asset for Dreamio, a cozy browser arcade and avatar dress-up website. True lovingly detailed 16-bit pixel game art, crisp square pixels, charming pastel lavender / powder blue / strawberry pink / butter yellow palette. Wide landscape 1536x1024 composition. A whimsical floating cloud city at late afternoon: layered fluffy stepped pixel clouds in foreground, dreamy lavender and periwinkle city skyline far behind, a small detailed pink-roofed arcade shop on a floating island at right, an illuminated little crescent moon, stars, potted flowers, and a winding tiled platform across bottom. The top left and center area should be spacious clean pale blue/lavender sky for website heading overlays. Main visual detail concentrated in bottom half and right third. Soft light, nostalgic cozy Nintendo DS game mood, very high quality and textured but clearly pixel art, no blur. No people, no characters, no text, no typography, no logos, no watermarks. This is a production website background, not a website mockup. Inspiration: pastel kawaii pixel game cities and dressup games.
